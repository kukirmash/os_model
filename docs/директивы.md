# Директивы оператора модели ОС (лабораторная работа 9)

Документ описывает язык управления моделью: директивы, их параметры,
горячие клавиши и ограничения.

## 1. Язык управления

| Директива | Параметры | Действие | Клавиша |
|---|---|---|---|
| Выключить питание | — | немедленное завершение модели | `Q` |
| Изменить скорость | ±10 % | изменение скорости | `+` / `−` |
| Пауза модели | — | приостановить моделирование | `Space` |
| Продолжить модель | — | продолжить моделирование | `Space` |
| Пауза автозагрузки | — | новые задания не создаются автоматически | `A` |
| Продолжить автозагрузку | — | автоматическая загрузка возобновляется | `A` |
| Загрузить задание | — | загрузить задание вручную | `L` |
| Задать параметры следующего задания | размер, команды, ВВ %, приоритет | разовое переопределение следующего задания | форма |
| Сбросить параметры задания | — | вернуть генерацию по диапазонам `params.json` | кнопка |
| Приостановить процесс | ID выбранного процесса | «Готов»/«Активен» → «Приостановлен» | `P` |
| Активизировать процесс | ID выбранного процесса | «Приостановлен» → «Готов» | `P` |
| Уничтожить процесс | ID выбранного процесса | выгрузка без зачёта как выполненного | `Delete` |
| Выполнить загруженные и выключить | — | запрет автозагрузки, ожидание пустой таблицы PSW, затем завершение | `F` |
| Изменить размер памяти | новый объём | изменение общего объёма памяти | форма |
| Задать seed RNG | целое число | переопределение seed при запуске | `-seed` |

## 2. Выбор процесса

Процесс выбирается щелчком по строке таблицы PSW. Выбранная строка
подсвечивается. В панели «Директивы оператора» отображаются номер и состояние
выбранного процесса.

Приостановить можно процесс в состоянии «Готов» или «Активен». Если процесс
активен, центральный процессор освобождается. Процесс в состоянии
«Инициализация IO» или «Блокирован» приостановить нельзя — директива
отклоняется с сообщением.

## 3. Уничтожение процесса

При уничтожении процесса:

- процесс удаляется из очереди готовности и таблицы PSW;
- занимаемая память освобождается;
- если процесс был активен, центральный процессор освобождается;
- если процесс был связан с ВВ, операция и ожидающее прерывание отменяются;
- процесс **не считается выполненным**: `Completed` не увеличивается;
- увеличивается отдельный счётчик `DestroyedCount`.

Баланс загруженных процессов:

```text
LoadedCount = CompletedCount + ResidentCount + DestroyedCount
```

## 4. Параметры следующего задания

Оператор может задать размер, число команд, процент команд ВВ и базовый
приоритет следующего задания. Переопределение действует один раз: после
успешной загрузки оно сбрасывается, и дальнейшие задания снова генерируются
по диапазонам `params.json`.

Если задание не удалось загрузить из-за памяти или свободного места в PSW,
переопределение сохраняется для повторной попытки.

## 5. Изменение памяти

Новый объём памяти должен быть больше нуля и не меньше уже занятого объёма.
При уменьшении ниже занятой памяти директива отклоняется с сообщением.
При успешном изменении обновляются `Memory.TotalSize` и `Config.MemorySize`.

## 6. Выполнить загруженные и выключить

Директива:

- отключает автоматическую загрузку новых заданий;
- снимает паузу модели;
- возобновляет все приостановленные процессы;
- завершает моделирование, когда таблица PSW становится пустой.

## 7. Seed из командной строки

Seed можно задать при запуске:

```sh
# консольный режим
go run ./cmd/osmodel -seed 12345

# Wails-приложение
./build/bin/os_model -seed 12345
```

Приоритет: `-seed` > `seed` из `params.json` > `Params.DefaultSeed`.
Одинаковый seed и одинаковый `params.json` дают одинаковую последовательность
параметров, заданий, команд и длительностей ВВ.

## 8. Результат директивы

Результат последней выполненной директивы отображается в панели
«Директивы оператора»: такт, имя директивы и сообщение об успехе или причине
отказа.
