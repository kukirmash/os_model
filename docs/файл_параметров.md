# Файл параметров модели ОС (лабораторная работа 8)

Входные параметры модели хранятся в JSON-файле `params.json`. Файл читается
**один раз при запуске** модели. Для каждого параметра задаются:

- `min` — минимальное значение;
- `max` — максимальное значение;
- `step` — дискретность;
- `comment` — комментарий для индикации.

## 2. Параметры

| Поле | Назначение | Ограничения |
|---|---|---|
| `seed` | зерно генератора псевдослучайных чисел | целое; при `0` используется `DefaultSeed` |
| `system.memorySize` | объём моделируемой памяти | `min >= 1` |
| `system.tickDurationMs` | длительность такта, мс | `min >= 1` |
| `system.ioMaxDuration` | максимальная длительность ВВ | `min >= 1` |
| `system.costs.load` | затраты на загрузку | `min >= 0` |
| `system.costs.dispatch` | затраты на выбор процесса | `min >= 0` |
| `system.costs.ioInit` | затраты на инициализацию ВВ | `min >= 0` |
| `system.costs.ioInterrupt` | затраты на прерывание ВВ | `min >= 0` |
| `system.costs.terminate` | затраты на завершение | `min >= 0` |
| `task.size` | размер задания | `min >= 1` |
| `task.commands` | число команд | `min >= 1` |
| `task.ioPercent` | процент команд ВВ | `0..100` |
| `task.basePriority` | базовый приоритет | `min >= 1` |

Для всех параметров:

```text
step > 0
min <= max
```

## 3. Генерация значения

Значение генерируется по диапазону и дискретности:

```text
count = (max - min) / step + 1
value = min + random(count) * step
```

Если `max` не кратен `step`, последнее возможное значение не превышает `max`.

## 4. Повторяемость

Модель использует один генератор `math/rand/v2` с фиксированным зерном:

```go
rand.New(rand.NewPCG(seed, seed))
```

Один и тот же `params.json` и `seed` дают одинаковую последовательность:

- системных параметров;
- параметров заданий;
- типов команд, адресов операндов и длительностей ВВ.

Это позволяет повторять эксперименты и сравнивать результаты запусков.

## 5. Чтение файла

Файл читается в точках входа:

- Wails-приложение — `app.startup`;
- консольный режим — `cmd/osmodel`.

Путь можно задать переменной окружения `OS_MODEL_PARAMS`; по умолчанию
используется `params.json`. При ошибке чтения или валидации Wails-приложение
продолжает работу со значениями по умолчанию, а текст ошибки отображается
в панели «Параметры из JSON-файла».

## 6. Проверка корректности

При чтении проверяются:

- наличие всех обязательных полей;
- целочисленность значений;
- `step > 0`;
- `min <= max`;
- допустимые границы для памяти, такта, ВВ, команд, процента ВВ и приоритета.

## 7. Отображение в интерфейсе

Панель «Параметры из JSON-файла» показывает:

- имя файла и статус загрузки;
- `seed`;
- таблицу параметров: имя, минимум, максимум, шаг, комментарий.

Панель «Параметры нового задания» показывает диапазоны и шаг для размера,
числа команд, процента ВВ и приоритета. Панели «Параметры системы» и
«Затраты ОС на системные действия» показывают уже сгенерированные значения.
